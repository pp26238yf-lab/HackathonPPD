使い方
1. ZIPをすべて展開してください。
2. index.htmlをEdge / Chromeなどのブラウザーで開きます。ネット接続やサーバーは不要です。
3. 名前・読み・英名で検索し、カードを開きます。
4. 左の図をクリックすると原寸の教材図を開けます。カード下に図の出典・構造の説明・メモ欄があります。
5. cardsフォルダーのPNGは、1枚ずつ画像として利用できます（1536×1024ピクセル）。

ほかのチャットへ渡すとき
・画像だけを渡す場合も、sources.csvとこのREADMEを添付してください。
・修正や再制作を依頼する場合は、一式のZIPを渡してください。data.jsonに全文と出典、card.html / style.css / card.jsに共通配置が入っています。
・メモは利用中のブラウザー内に保存します。別のブラウザーや別の端末へは自動移行しません。

収録範囲
ご指定の一覧の重複（外陰部、陰茎、大動脈、気管、尿管）を統合した158種類です。
腎臓全体の試作は今回の列挙158種類には含まれず、腎皮質・腎髄質・腎盂を収録しています。
未作成カード：0種類。
外陰部・陰茎・陰嚢・精管の4枚は共通の案内キャラクターを使用します。

見本からの変更
・配色、左右構成、右上のキャラクター欄、位置欄、3段の働き、補足欄、メモボタンを共通テンプレート化。
・名称は最新の腋窩リンパ節の見本に合わせ、左図の下に「読み→名称→英名」で統一。
・長い名称・文章は、枠の位置を動かさず文字サイズを調整。
・解剖図は、出典を追えるOpenStax教材図、Grayの解剖図、BodyParts3Dの立体モデルを使用。
・手掌・足底・背部の皮膚・肘の皮膚・かかとの5枚は、外観とラベルを確認した既存の体表図を継続使用。
・教材図の英語ラベルは原図のまま保持。対象の日本語名・英名を図の下に併記。
・各カードの案内キャラクターは解剖図ではありません。骨の数・分枝などの学習には左の図と本文を使用してください。
