# からだレイヤー

## 最新：添付カード・裏面メモ（2026-10-08）

202種類の添付画像をカード対象205 IDすべてに対応させました。「メモに移動」で共通の裏面へ反転し、カード別にブラウザーへ自動保存します。皮膚・脳・心臓・目・耳・肺・腎臓・骨盤内生殖器はカードではなく拡大入口です。保存制限・出典・検証範囲は [CARD-NOTES.md](CARD-NOTES.md) を参照してください。下記の過去記録にある「カード差し替え用」の説明は、この更新で置き換えられています。

カード検証：`node verify-cards.cjs`。提供資料の利用条件・図版クレジットを維持してください。

人体を「服・皮膚・筋肉・骨・神経／血管／リンパ・臓器」の6層で切り替えながら学ぶ、大学ハッカソン向けのインタラクティブWebアプリです。全層に正面・背面表示があり、皮膚・脳・目・耳・心臓・肺・腎臓には専用の内部構造ビューがあります。臓器層の骨盤内生殖器も男女別に拡大できます。

## 起動方法

`index.html` をブラウザで開くだけで動作します。ローカルサーバーを使う場合は、このフォルダを公開ディレクトリに指定してください。

## 実装済み

- 皮膚・脳・目・耳・心臓・肺・腎臓の拡大図を質感のある医療イラストに変更。赤丸は各画像に合わせた座標で配置
- 骨盤内拡大からは左下の矢印で臓器層の全身に戻る。上部の戻るボタンは削除
- 服の画像ファイルは保持し、画面高に合わせた表示枠へ全身を収める
- 6つの全身レイヤーと前後移動
- 全身レイヤー共通の正面・背面切り替え
- 統合ネットワーク層の中枢神経・末梢神経・動脈・静脈・リンパ絞り込み
- アイコンと名称を併記したレイヤーナビゲーション
- 人体図の横に配置した、層・向き・モデルに連動する縦スクロール式部位一覧
- スマートフォン向けボトムシート型カード
- レイヤーへ直接移動するナビゲーション
- 筋肉・骨・神経・血管・リンパ節・内臓・感覚器・皮膚付属器を含む140種類以上の独立したタップ対象
- カードデータ未登録でも反応する共通プレースホルダーカード機構
- 皮膚・脳・目・耳・心臓・肺・腎臓の内部構造ビュー
- 内部構造内の細かな組織をタップして開く情報カード
- 通常カード対象の赤丸と、内部構造へ移動する虫眼鏡マークの区別
- 部位一覧では名前の選択で該当箇所・虫眼鏡を点滅させ、「カードを開く」「拡大する」は別ボタンで実行
- 骨盤内だけを描画する男女別拡大図と、内部構造ビューに共通の赤丸マーカー
- 骨盤内の別枠拡大図は通常表示せず、人体の骨盤部の虫眼鏡、または一覧の「拡大する」から表示
- 一覧で選択した臓器の塗りと線を赤・黄色で点滅させ、虫眼鏡も強調
- PC／スマートフォン対応
- 左右キー操作、ダイアログ、効果音ON/OFF

## コンテンツ追加箇所

### 拡大図の画像

`detail-illustrations.js` に7種類の拡大画像と選択座標を登録しています。画像は `assets/detail-*.png` です。生成条件・参照資料・確認範囲は `IMAGE-NOTES.md` を参照してください。骨盤内の画像生成は生成サービスの安全判定で拒否されたため、従来の模式図を保持しています。

### 一覧と描画の改善（2026-10-07）

- 前面と背面で異なる神経・血管・リンパの走行と選択対象を描画。背面は肩甲部、膝窩、後脛骨などを追加。
- 部位一覧を人体図の上へ移動。名称選択で図中のマーカーが点滅し、隣に出る「カードを開く」から表示します。
- 内部構造を持つ部位を一覧から選ぶと、その内部構造図と部位一覧へ進みます。内部の細部も名称選択後にカードを開けます。
- 筋肉・骨・神経／血管／リンパ・臓器では肌色の塗りを使わず、輪郭をガイド線で示します。服は襟・ポケット・縫い目・陰影を加え、男女の髪形と衣服の線を分けました。
- `node card-catalog.cjs` で、全レイヤーと各内部構造の現在のカード対象名を描画データから確認できます。


### 全身画像の更新（2026-10-08）

皮膚・骨格・臓器は男女別のリアル調生成画像（正面／背面）に変更。服と拡大図は維持。筋肉とネットワークの画像置換は未完了で、既存SVGを維持しています。詳しい制限・プロンプト・公開方法は `FULL-BODY-NOTES.md` を参照。画像は監修前の学習用で、赤丸は隠れた部位も含む位置の目安です。

検証: `node verify-atlas.cjs`、`node verify-details.cjs`、`node verify-full-body.cjs`。

### 男女別人体図（2026-10-05）

- 全身図の描画を `anatomy-atlas.js` の独自SVGに更新。添付参考図の輪郭・色分けを参考にし、画像そのものは転載していません。
- 男性／女性をボタンで切り替え、6層すべてで正面／背面を表示。輪郭と骨盤の模式形状もモデル別です。体格や器官の形態には個人差があります。
- 女性：子宮、子宮頸部、卵巣、卵管、腟、外陰部。男性：前立腺、精巣、精巣上体、精嚢、精管、陰茎、陰嚢（皮膚層）。乳腺は両モデルで表示します。
- 臓器層には選択モデルの生殖器拡大図と「骨盤内を拡大」を追加。拡大図は全身の向きとは別の正面模式図です。臓器層の正面は各モデル48対象（臓器の各部・感覚器も含む）。
- 部位一覧は服以外の各全身層で利用可能。選択した性別・向き・ネットワーク絞り込みに追従します。カード本文は引き続き差し替え用です。
- 全身SVGの部位・座標は `atlasNames` / `atlasMusclePoints` / `atlasBonePoints` / `atlasOrganPoints` と `atlasSVG()` で管理。旧全身描画関数は現在使用していません。内部構造ビューは既存の `app.js` に残しています。

検証：`node verify-atlas.cjs`（24通りの描画、男女固有の器官の分離、既存追加筋肉・骨IDの保持）。

部位選定の参考：OpenStax [男性生殖器](https://openstax.org/books/anatomy-and-physiology/pages/27-1-anatomy-and-physiology-of-the-male-reproductive-system)、[女性生殖器](https://openstax.org/books/anatomy-and-physiology/pages/27-2-anatomy-and-physiology-of-the-female-reproductive-system)。画像・本文の転載はしていません。

### 先行する部位追加の記録

2026-10-05: 筋肉30項目・骨26項目・臓器など21項目を追加。筋肉層はアキレス腱と筋群を含む44項目、骨層は骨群を含む37項目、臓器層は感覚器・臓器の各部を含む50項目（正面・背面の同一IDは重複計上しない）。

- 筋肉：側頭筋、咬筋、眼輪筋、口輪筋、胸鎖乳突筋、前鋸筋、外腹斜筋、上腕筋、腕橈骨筋、橈側手根屈筋、尺側手根屈筋、腸腰筋、縫工筋、大腿直筋、外側広筋、内側広筋、長内転筋、薄筋、長腓骨筋、長趾伸筋、棘下筋、大円筋、大菱形筋、脊柱起立筋、総指伸筋、中臀筋、大腿二頭筋、半腱様筋、半膜様筋、ヒラメ筋。
- 骨：前頭骨、側頭骨、頬骨、鼻骨、上顎骨、下顎骨、橈骨、尺骨、手根骨、中手骨、指骨（手）、腸骨、坐骨、恥骨、脛骨、腓骨、距骨、中足骨、趾骨（足）、頭頂骨、後頭骨、頸椎、胸椎、腰椎、尾骨、踵骨。
- 臓器など：喉頭、耳下腺、顎下腺、十二指腸、空腸、回腸、盲腸、上行結腸、横行結腸、下行結腸、S状結腸、子宮、卵巣、卵管、腟、前立腺、精巣、精巣上体、精嚢、精管、尿道。既存の脾臓は描画とタッチ領域を揃え、背面の位置も修正。

追加部位は `expanded-parts.js` の `expandedParts` に定義。並びは `[ID, 名称, 正面/背面, x, y, 分類, 任意の模式線, 深部フラグ]`。人体の位置は模式的で、深部の筋は重ね合わせ、生殖器は男女別の独立した拡大模式図で表示する。厳密な深さや大きさを示すものではない。

筋肉・骨・臓器の部位一覧は描画されたホットスポットから重複を除いて自動生成する。名称検索・キーボード操作に対応。各カードは引き続き画像・本文差し替え用の枠とし、既存の内部構造への直接遷移を維持。

部位選定の参考：OpenStax Anatomy and Physiology 2e [下肢の筋](https://openstax.org/books/anatomy-and-physiology-2e/pages/11-6-appendicular-muscles-of-the-pelvic-girdle-and-lower-limbs)、[上肢の骨](https://openstax.org/books/anatomy-and-physiology-2e/pages/8-2-bones-of-the-upper-limb)、[小腸・大腸](https://openstax.org/books/anatomy-and-physiology-2e/pages/23-5-the-small-and-large-intestines)。図は独自の簡略図。

組織名・カード文は `app.js` の `items`、レイヤーの説明は `layers` にまとまっています。新しいSVG部位に `class="hotspot"`、`data-item`、`data-label`、`data-type` を付けると、カード内容が未登録でも自動的に反応します。医学情報や正式な画像が届いたら、このデータと各SVG／画像を差し替えられます。
